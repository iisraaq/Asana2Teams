# Asana plus

Aplicación para macOS con marca **A+**. Este repositorio público contiene instaladores y el catálogo de actualizaciones; el código se mantiene en el repositorio privado `iisraaq/AsanaPlus-source`.

El nombre vigente es **Asana plus**. La URL histórica `iisraaq/Asana2Teams` se conserva por compatibilidad con el actualizador de versiones instaladas. Cambiar el nombre visible no significa que se haya publicado otra versión ni que las funciones en pruebas estén aprobadas.

Descarga desde [Releases](https://github.com/iisraaq/Asana2Teams/releases) y revisa las notas de cada versión. Las publicaciones marcadas como pruebas no sustituyen al canal estable.
